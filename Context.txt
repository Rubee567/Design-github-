1.0 DEFINITION OF A COMPUTER 
A Computer is an electronic device that accepts data (input), processes the data according to a set of instructions (program), stores the data, and produces useful information (output).

The word COMPUTER comes from the word COMPUTE which means to calculate.

2.0 CHARACTERISTICS / FEATURES OF COMPUTER
1.  Speed: It works at very high speed, millions of operations per second. Measured in Nanoseconds.
2.  Accuracy: It gives 100% accurate result if the input is correct. GIGO - Garbage In Garbage Out.
3.  Storage: It can store large amount of data and information for a long time.
4.  Versatility: It can perform many different tasks at the same time.
5.  Automation: Once you give it instruction, it works automatically without human help.
6.  Diligence: It does not get tired or lazy, it can work 24 hours.
7.  No IQ: It has no intelligence of its own, it depends on human.

3.0 CLASSIFICATION OF COMPUTER

A. BY OPERATION / TYPE
1.  Analog Computer: Measures continuous data like temperature, speed, pressure. E.g Thermometer, Speedometer of car.
2.  Digital Computer: Works with discrete data (0 and 1). Most common today. E.g Laptop, Phone.
3.  Hybrid Computer: Combines analog and digital features. E.g ECG machine in hospital, Fuel pump station.

B. BY SIZE / CAPACITY / CLASS
1.  Super Computer: Largest, fastest, most expensive. Used for weather forecasting, space research, nuclear research. E.g Cray-1
2.  Mainframe Computer: Very large, can serve hundreds of users at once. Used in banks, INEC, large companies.
3.  Minicomputer: Medium size, less powerful than mainframe. Used in labs, production control.
4.  Microcomputer: Smallest and cheapest. Used in homes, schools, offices. E.g Desktop, Laptop, Tablet, Smartphone.

C. BY PURPOSE
1.  General Purpose Computer - Can do many tasks
2.  Special Purpose Computer - Designed for one specific task e.g traffic control

4.0 GENERATIONS OF COMPUTER

1st Generation (1940-1956)
- Technology: Vacuum Tubes
- Memory: Magnetic Drum
- Size: Very big, occupied full room
- Speed: Very slow
- Heat: Generated too much heat
- Example: ENIAC, UNIVAC

2nd Generation (1956-1963)
- Technology: Transistors
- Memory: Magnetic Core
- Size: Smaller than 1st
- Speed: Faster, more reliable
- Language: Assembly Language and FORTRAN, COBOL
- Example: IBM 1401

3rd Generation (1964-1971)
- Technology: Integrated Circuit (IC)
- Memory: Improved
- Size: Smaller
- Speed: Much faster, keyboards and monitors introduced
- Language: High Level Language
- Example: IBM 360 series

4th Generation (1971-Present)
- Technology: Microprocessor / VLSI (Very Large Scale Integration)
- Memory: Semiconductor memory
- Size: Very small - Laptop, Palmtop
- Speed: Very very fast, millions of operations
- Language: GUIs, Internet, Windows
- Example: All modern computers, Apple Macintosh

5th Generation (Present & Future)
- Technology: ULSI (Ultra Large Scale Integration) and Artificial Intelligence (AI)
- Feature: Can think, reason, learn like human
- Focus: Robotics, Voice recognition, Machine Learning
- Example: Robots, ChatGPT, Self-driving cars

5.0 COMPONENTS OF COMPUTER SYSTEM
A computer system has 3 main components:

1. Hardware: Physical parts you can see and touch.
- Input devices: Keyboard, Mouse, Scanner, Joystick
- Output devices: Monitor, Printer, Speaker
- System Unit: Motherboard, CPU, RAM, Hard Disk
- Storage devices: Flash drive, Hard disk, Memory card

2. Software: Set of instructions/programs that tell hardware what to do.
- System Software: Controls the computer itself e.g Windows 10/11, Linux, MacOS
- Application Software: For specific tasks e.g MS Word, Excel, CorelDraw, VLC, WhatsApp

3. Peopleware / Humanware: The people who use the computer.
- Programmers, Operators, End Users

6.0 ADVANTAGES OF COMPUTER
- Makes work faster
- Stores information safely
- Connects people via internet
- Helps in education, banking, hospitals
- For entertainment

7.0 DISADVANTAGES
- Causes unemployment
- Causes eye problem if overused
- Can be hacked / virus attack
- Makes people lazy
- Expensive to buy and maintain
